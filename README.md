# 🎮 Rock Paper Scissors Game

Simple Python console game implementing game logic, input validation, and loop control.

## ✨ Features
- Input validation (`player in options`)
- Infinite game loop (`while True`)
- Automatic tie replay (`continue`)
- Clean exit handling
- Win/loss/tie detection

## 🚀 Quick Start
```bash
python rps.py
```
